| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |The CPU processes instructions, performs calculations and controls other computer components.

 | Clock speed measures how fast it works. Cores determine how many tasks it can handle at once.
 Cache stores frequently used data for faster access. |
| RAM |temporarily stores data and programs that the computer is currently using. | Capacity (GB)
 determines how much data it can store. Speed (MHz) affects how quickly data can be accessed. |
| Storage |Storage saves files, programs and data permanently, even when the computer is turned off. |Capacity (GB or TB) 
determines how much data it can hold. Speed affects how quickly files can be read and saved. |
| Motherboard |The motherboard connects all the computer components and allows them to communicate with each other. 
|Size (form factor), number of slots and ports, and CPU compatibility. |
| Power Supply |The power supply provides electricity to all the computer components. |Wattage (W) determines 
how much power it can provide. Efficiency rating shows how well it uses electricity. |
| Cooling |Cooling prevents computer components from overheating by removing excess heat. 
| Cooling type (air or liquid), fan speed (RPM) and noise level (dB).|
