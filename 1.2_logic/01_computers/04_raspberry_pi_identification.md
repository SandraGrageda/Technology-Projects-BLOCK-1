| Component | Function |
|-----------|----------|
| SoC |combines the CPU, GPU and other components into one chip. It processes data and helps the Raspberry Pi run programs. |
| GPIO |pins allow the Raspberry Pi to connect and communicate with external devices such as sensors, LEDs and buttons. |
| USB |ports allow the Raspberry Pi to connect external devices such as keyboards, mice, USB drives and other accessories. |
| HDMI |port connects the Raspberry Pi to a monitor or TV to display video and audio. |
| Power |input supplies electricity to the Raspberry Pi so it can turn on and operate. |
| microSD |card stores the operating system, programs and files needed for the Raspberry Pi to work. |
| Network | connection allows the Raspberry Pi to connect to the internet or other devices through Wi-Fi or Ethernet.|
| Wireless |allows the Raspberry Pi to connect to devices and the internet using Wi-Fi or Bluetooth without cables. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Many components are integrated into a single board in embedded computers like the Raspberry Pi to save space 
and make the device smaller and more compact. It also helps reduce production costs because fewer separate 
parts are needed. Having everything on one board allows the components to communicate with each other more 
easily and efficiently. Another advantage is that it uses less power and makes the device easier to install in 
different projects. This is especially useful for embedded systems because they are designed to perform specific 
tasks without needing a large or complicated computer setup. It also makes them easier to carry and use in 
different environments.
