## Explain Software
Write **at least 50 words** explaining what software is.
--- Software is a set of programs and instructions that tell a computer what to do. 
Unlike hardware you cannot physically touch software. Examples include Google 
Chrome, Microsoft Word and operating systems like Windows. Software allows users to
perform different tasks such as browsing the internet, writing documents 
and playing games. Without software the hardware would not know what to do.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
--- Hardware and software work together to make a computer function. Software 
gives instructions to the hardware and the hardware carries them out. For 
example when you open a program the software sends instructions to the CPU which 
processes the information. The results are then shown on the monitor. They both 
depend on each other because hardware needs software to work properly and software 
needs hardware to run.
